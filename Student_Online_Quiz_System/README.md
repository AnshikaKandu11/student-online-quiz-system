# Student Online Quiz System

## Project Type
Web-based Student Online Quiz System.

## Technologies
- HTML
- CSS
- JavaScript
- Bootstrap-ready frontend structure
- PHP
- MySQL
- XAMPP / Apache

## How to Run in VS Code + XAMPP

1. Install XAMPP.
2. Start Apache and MySQL from the XAMPP Control Panel.
3. Copy the `Student_Online_Quiz_System` folder into:
   `C:\xampp\htdocs\`
4. Open the folder in Visual Studio Code.
5. Open phpMyAdmin:
   `http://localhost/phpmyadmin`
6. Create/import the database using:
   `database/database.sql`
7. Open the project:
   `http://localhost/Student_Online_Quiz_System/`
